Wenn du **ein Konzept isoliert sehen** willst, sind die
eigenständigen Snippets der richtige Ort.  Jedes ist eine
einzelne Datei, die ein Pattern demonstriert - kein Docker,
keine Peers, lauffähig mit `bun`.

Zu finden in
[`examples/`](https://github.com/pathosDev/actor-ts/tree/main/examples)
im Repo - die grundlegenden liegen auf oberster Ebene, der Rest in
themenbezogenen Unterverzeichnissen (`patterns/`, `persistence/`,
`cluster/`, `fsm/`, `pubsub/`, `crdt/`, `typed/`, `management/`, …).

## Ausführen

```bash
git clone https://github.com/pathosDev/actor-ts.git
cd actor-ts

bun install
bun examples/hello-world.ts
```

Jedes Snippet läuft bis zum Ende und beendet sich.  Keine
langlaufenden Prozesse; keine externen Abhängigkeiten.

Für cluster-bezogene Snippets (Singleton, Sharding, PubSub, DD)
nutzen die Snippets **`MultiNodeSpec`**, um einen Cluster
innerhalb eines Prozesses zu simulieren - kein Docker nötig.

## Patterns

Die meisten Snippets folgen demselben Aufbau:

```ts
import { ActorSystem, ... } from 'actor-ts';
import { ... } from 'actor-ts/<subsystem>';

// 1. System + Actors aufsetzen.
const system = ActorSystem.create('demo');
const ref = system.spawnAnonymous(MyActor);

// 2. Ein paar Nachrichten senden.
ref.tell({ ... });
ref.tell({ ... });

// 3. Auf Verarbeitung warten (kleines await oder expect auf einer Probe).
await new Promise(r => setTimeout(r, 100));

// 4. Ergebnis ausgeben + aufräumen.
console.log(...);
await system.terminate();
```

Für komplexere Flows (Cluster, Persistenz) nutzen die Snippets
`TestKit` + `TestProbe` für sauberes Teardown.

## Anpassen

Snippets sind der einfachste Ort zum **Experimentieren**:

```bash
# Kopieren, editieren, ausführen:
cp examples/hello-world.ts examples/my-experiment.ts
# examples/my-experiment.ts editieren
bun examples/my-experiment.ts
```

Das Framework wird über das `actor-ts`-Package des lokalen Repos
eingebunden - deine Edits laufen gegen die Live-Quelle.

## Snippets beitragen

Wenn du ein cleveres Pattern erarbeitet hast, **stelle einen
PR mit einem Snippet**.  Kriterien:

- **Eine Datei, ≤ 200 Zeilen.**
- **Ein Konzept** klar demonstriert.
- **Self-contained** - lauffähig ohne externe Services.
- **Kommentare**, die erklären, was der Code zeigt.

Lege sie für ein grundlegendes Konzept auf oberster Ebene von
`examples/` ab, sonst im passenden themenbezogenen Unterverzeichnis;
füge dann eine Zeile zur obigen Tabelle hinzu.
